Understanding the Metrics

Precision
Of all predicted accidents, how many actually occurred?

High precision = Few false alarms
Recall
Of all actual accidents, how many were predicted?

High recall = Few missed accidents
F1 Score
Harmonic mean of precision and recall.

Balanced metric for overall performance
The Paradox
A model can have high accuracy but poor predictive power.

Look beyond accuracy for true performance
